# Cyber Color Picker 要件定義書

Oct 5, 2026 · @halohalo

## 1. 概要

Google検索のカラーピッカーと同等の操作性を持ち、ネオン発光のサイバーパンクデザインを纏った単一HTMLカラーツール「Cyber Color Picker」を作る。

- **目的**：色の選択・変換・配色検討・書き出しを1画面で完結させる
- **参考**：Google検索「カラーピッカー」ウィジェット（彩度/明度エリア＋色相スライダー＋各形式の値表示）
- **対象外**：アカウント管理、サーバー保存、複数人での同時編集

## 2. 提供形態・技術要件

ブラウザで開くだけで動く、サーバー不要の単一HTMLファイルとする。

| 項目 | 要件 |
| --- | --- |
| ファイル構成 | HTML・CSS・JSを1ファイルに集約 |
| 実装 | バニラJS（フレームワーク不使用） |
| 外部依存 | Webフォントのみ許容。オフライン時は系統フォントで代替 |
| 対応ブラウザ | Chrome / Edge / Safari / Firefox の最新版 |
| 保存先 | localStorage（履歴・お気に入り・テーマ） |
| 色変換 | 自前実装（HEX/RGB/HSV/HSL/CMYK/OKLCH/LABの相互変換） |

## 3. 機能要件：ピッカー本体・カラー形式

ピッカー操作と全形式の値は常に双方向で同期する。どの入力欄を編集しても、他の形式とピッカー位置が即時に更新される。

**ピッカー操作**

- 彩度（横）×明度（縦）の2Dエリアをドラッグ/タップで選択
- 色相スライダー（0–360°）
- アルファスライダー（0–100%、市松模様背景）
- プレビュースウォッチ（現在色と直前色を並べて表示）
- キーボード操作（矢印キーで1単位、Shift併用で10単位移動）

**対応形式**

| 形式 | 表示例 | 入力 | 備考 |
| --- | --- | --- | --- |
| HEX | #00F0FF / #00F0FFCC | 可 | 3/4/6/8桁を受け付け |
| RGB(A) | rgb(0 240 255 / 0.8) | 可 |  |
| HSL(A) | hsl(184 100% 50% / 0.8) | 可 |  |
| HSV | 184°, 100%, 100% | 可 |  |
| CMYK | 100%, 6%, 0%, 0% | 可 | 単純変換（ICCプロファイル非対応） |
| OKLCH | oklch(0.88 0.15 200) | 可 |  |
| LAB | lab(88 -40 -20) | 可 |  |
| 色名 | "aqua" | 可 | CSS名前付き色148色。一致しない場合は最近似色を「≈」付きで表示 |

入力値が不正な場合はフィールドを赤く光らせ、直前の正常値を保持する。

## 4. 機能要件：追加機能

スポイト・履歴/お気に入り・配色パレット・コントラストチェックの4機能を搭載する。

**4.1 スポイト（EYEDROPPER）**

- EyeDropper APIで画面上の任意のピクセルから色を取得
- 非対応ブラウザ（Safari / Firefox）ではボタンを無効化し「NOT SUPPORTED」と表示
- 代替として画像ファイルをドロップし、画像内から色を拾う機能を設ける

**4.2 履歴・お気に入り（HISTORY / FAVORITES）**

- 履歴：コピーまたは確定した色を自動記録、最大30件（古いものから削除）
- お気に入り：★ボタンで保存、最大100件、名前の付与と削除が可能
- スウォッチをクリックでその色をピッカーに反映
- localStorageに保存し、次回起動時に復元

**4.3 配色パレット生成（HARMONY）**

- 補色 / 類似色 / トライアド / スプリット補色 / テトラドをタブで切替
- 濃淡シェード：現在色から明→暗の9段階（50–900相当）を生成
- 各スウォッチはクリックでコピー、ダブルクリックでメイン色に設定

**4.4 コントラストチェック（CONTRAST）**

- 文字色と背景色をそれぞれ指定（現在色・履歴から選択可）
- WCAG 2.xのコントラスト比を表示し、AA（4.5:1）/ AA Large（3:1）/ AAA（7:1）の合否をPASS/FAILで表示
- サンプルテキストで実際の見え方をプレビュー
- 文字色と背景色の入れ替えボタン

## 5. 機能要件：出力・共有

コピー・コード書き出し・PNG保存・URL共有の4経路を用意する。

| 機能 | 対象 | 仕様 |
| --- | --- | --- |
| ワンクリックコピー | 各形式の値、各スウォッチ | コピー時に「COPIED」トースト＋ネオンフラッシュ |
| コード書き出し | 現在色＋パレット＋シェード | CSS変数 / JSON / Tailwind設定をタブで切替、コードブロック表示＋コピー |
| PNG保存 | パレット＋シェード | Canvasで描画し、各色に HEX ラベル付きでダウンロード |
| URL共有 | 現在色（＋配色モード） | URLハッシュに保持（例：#00f0ffcc&h=triad）。開いたときに同じ状態を再現 |

単一HTMLをローカルで開く場合、URL共有は同じファイルを持つ相手にのみ有効。不特定多数への共有にはホスティングが必要。

## 6. UI・デザイン要件

ダークモードをネオングロー系サイバーパンクの主舞台とし、ライトモードは同じアクセント色を使ったシンプルな作業向け表示とする。

**テーマ**

| 要素 | ダーク（メイン） | ライト（シンプル） |
| --- | --- | --- |
| 背景 | 濃紺〜黒（#0A0A14前後）＋シアンの細いグリッド | オフホワイト、グリッドなし |
| アクセント | シアン #00F0FF＋マゼンタ #FF2BD6 | 同系統の濃色を線・文字に限定使用 |
| 発光 | パネル枠・ボタン・スライダーつまみにbox-shadow/text-shadowのグロー | なし（薄い影のみ） |
| パネル | 半透明ダーク＋ネオン枠 | 白パネル＋細いグレー枠 |

- 右上のトグルで切替。初期値はOS設定（prefers-color-scheme）に追従し、切替結果はlocalStorageに記憶

**タイポグラフィ・言語**

- UIは英語。ラベルは大文字（HUE / ALPHA / EXPORT など）
- 見出しは未来的なディスプレイ書体、値表示は等幅フォント

**アニメーション（中程度・ダークのみ）**

- パネル枠の発光がゆっくり強弱（周期3–4秒）
- ホバー・フォーカス時にグロー強調
- コピー時に対象が一瞬フラッシュ
- prefers-reduced-motion 有効時は全アニメーションを停止

## 7. 画面構成

1画面構成で、PCでは左にピッカー、右にツール群を配置する。スマホでは上から順に縦積み。

| 順 | エリア | PCの位置 | 主な要素 |
| --- | --- | --- | --- |
| 1 | HEADER | 上部全幅 | ロゴ、テーマ切替、共有ボタン |
| 2 | PICKER | 左カラム | 2Dエリア、HUE/ALPHAスライダー、プレビュー、スポイト、★ |
| 3 | VALUES | 左カラム下 | 全形式の入力欄＋コピーボタン、色名 |
| 4 | HARMONY | 右カラム | 配色モードタブ、スウォッチ、濃淡シェード |
| 5 | CONTRAST | 右カラム | 文字色/背景色、比率、PASS/FAIL、プレビュー |
| 6 | EXPORT | 右カラム | CSS / JSON / Tailwindタブ、PNG保存 |
| 7 | HISTORY / FAVORITES | 下部全幅 | 履歴スウォッチ列、お気に入り一覧 |

## 8. 非機能要件

操作の追従性と読みやすさを演出より優先する。

| 区分 | 要件 |
| --- | --- |
| 性能 | ドラッグ中60fpsを維持（描画はrequestAnimationFrameで間引き）。初期表示1秒以内 |
| ファイルサイズ | 200KB以下を目安 |
| レスポンシブ | PC（1024px〜）は2カラム、スマホ（〜767px）は1カラム縦積み。横スクロールなし |
| タッチ | Pointer Eventsでマウス・タッチを統一。タップ領域44px以上 |
| アクセシビリティ | UI文字は両テーマでWCAG AA（4.5:1）を満たす。全操作をキーボードで可能、スライダーにARIA属性 |
| 保存 | localStorageが使えない環境でも動作（保存なしで継続、エラーを出さない） |
| 精度 | 形式間の往復変換でHEXが変わらないこと（丸め誤差±1以内） |

## 9. 優先度・受け入れ基準・未決事項

実装は3段階で進め、各段階の終わりに動作確認する。

| 段階 | 範囲 |
| --- | --- |
| P1（必須） | ピッカー本体、全カラー形式、コピー、テーマ切替、レスポンシブ |
| P2 | 履歴・お気に入り、配色パレット、コントラストチェック、スポイト |
| P3 | コード書き出し、PNG保存、URL共有、画像からの色取得 |

**受け入れ基準**

- [ ] 任意の形式に値を入力すると、他形式とピッカーが即時に同期する
- [ ] ダーク/ライトを切替え、再読み込み後も選択が保持される
- [ ] スマホ幅（375px）でレイアウトが崩れず、タッチで色を選べる
- [ ] コントラスト比が既知の組み合わせ（白×黒=21:1）で正しく表示される
- [ ] URLを開き直すと同じ色と配色モードが再現される
- [ ] キーボードのみで主要操作が完了できる

**未決事項**

- ツール名（仮：Cyber Color Picker）
- 起動時の初期色（仮：#00F0FF）
- 公開方法（ローカル利用のみか、GitHub Pages等でのホスティングも行うか）
